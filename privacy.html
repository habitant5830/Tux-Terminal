A simple personal blogging website developed using pure HTML and CSS covering most technological stuffs related to opensource, linux, privacy, security and more. This site is completely open-source and the source code is available on github as it is.

No Advertisements, analytics, trackers, or promotions are used at all and never will be.

I hosted this website on several free CDNs like GitHub Pages. Cloudflare Pages and Render. Even though this website itself doesn't collect any data about the visitors, it is possible that the CDNs I used to host may collect a significant amount of data about the usage and traffic of the websites hosted using their free service to improve allover usability and performance for everyone. Read these CDN providers privacy policy to know more about this type of data collection.
