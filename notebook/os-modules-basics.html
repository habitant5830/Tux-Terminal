Python: OS Module Basics

OS Module is a python built-in module. OS Modules helps us to interact with the system directly using python programming. For example, allows operations like moving a file, creating a file, deleting a file, etc.

Import the module using: 
import os

print()

no matter whichever keyword or function you use, If you want to display the output on the terminal inetractively, use print command: 

print()

Object Introspection

Object introspection is a way to know the attributes and functions included in this module. 

print(dir(os))

os.getcwd()

To know your current working directory, you can use: 
print(os.getcwd())

To Change CWD

os.chdir("<--path of new location-->")

Verify the change by trying to print the CWD again:

print(os.getcwd())

os.listdir()

This lists all the directories and files on the current working directory. 

print(os.listdir())

To list all directories and files in a specific path:

os.chdir("<--path url-->")

os.mkdir()

Used to create directory.

os.mkdir("<--directory_name-->")

Verify creation using:

print(os.listdir())

Create subfolders

To create subfolders you can use:

os.mkdir("<--directory_name/subfolder_name-->")

os.makedirs()

using os.makedirs(), you can create the main folder along with subfolders if it not exists yet. 

os.makedirs("<--directory_name/subfolder_name-->")

os.rename()

Helps to rename files. It takes two arguments.

os.rename("old_name","new_name")

Verify name change using:

print(os.listdir())

os.path.exists()

Helps us to verify that actually a path exists.

Verify creation using:

print(os.path.exists("<--path_url-->"))
The output will be printed like boolean values. (True/False).

You can replace exists with many other keywords like:

  • isfile
  • isabs
  • isdir
  • islink
