Void Linux Setup Guide

Void Linux Installation and Setup Guide

This guide assumes the glibc ISO and a USB drive of at least 4 GB. Back up important data before changing partitions or installing an operating system. Package availability can vary; check XBPS if a package cannot be found.

Install Void Linux

  1. Boot from the installation USB and log in to the live environment.
  2. Start the installer: 
    void-installer
  3. Set the keyboard layout, network, mirror, hostname, locale, timezone, root password, and user account in the installer.
  4. For a UEFI installation, create or select an EFI System Partition and a Linux root partition. Format the EFI partition as FAT32 and mount it at /boot/efi. Format the root partition as ext4 and mount it at /. Select the correct disk for the bootloader.
  5. Review the partition choices carefully, then run the installation.
  6. Leave the required default services enabled, reboot, and remove the USB drive.

First login and system update

Log in with the user account you created. Update the system:

sudo xbps-install -Syu

Network connection

If the installer did not configure networking, use the method appropriate for your setup. For a Wi-Fi connection, NetworkManager is installed below; connect through Plasma’s network settings or use nmtui.

Alternatively, for a temporary connection with wpa_supplicant, replace the interface name and network details with your own. Avoid putting a real Wi-Fi passphrase in shell history. 

ip link
sudo wpa_passphrase "YOUR_HOTSPOT_SSID" "YOUR_WIFI_PASSPHRASE" \
  | sudo tee /etc/wpa_supplicant/wpa_supplicant-INTERFACE.conf
sudo wpa_supplicant -B -i INTERFACE \
  -c /etc/wpa_supplicant/wpa_supplicant-INTERFACE.conf
sudo dhcpcd INTERFACE
ping -c 4 example.com

Install KDE Plasma non-meta packages and enable services

sudo xbps-install -S xorg dbus NetworkManager plasma-desktop kf6-kded plasma-workspace-wallpapers xdg-desktop-portal-kde kinfocenter kscreen powerdevil plasma-thunderbolt bluedevil plasma-nm plasma-pa kgamma kdeplasma-addons breeze-gtk kde-gtk-config kwallet-pam oxygen-qt6 ksshaskpass kwrited sddm-kcm elogind upower udisks2 dolphin kate konsole

Enable D-Bus, SDDM, and NetworkManager with runit:

sudo ln -s /etc/sv/dbus /var/service/
sudo ln -s /etc/sv/sddm /var/service/
sudo ln -s /etc/sv/NetworkManager /var/service/

Reboot to start Plasma. If you used dhcpcd as a separate service and are switching to NetworkManager, check its status first: 

sudo sv status dhcpcd

If the dhcpcd service is enabled and conflicts with your NetworkManager setup, disable it by removing its service link: 

sudo rm /var/service/dhcpcd

Applications

Install applications individually or in smaller groups. If XBPS reports that a package is unavailable, check its exact package name and whether it is available for your repository and architecture. 

sudo xbps-install -S nano ark spectacle plasma-browser-integration okular gwenview vivaldi libreoffice vscode haruna android-tools baobab octoxbps hugo nodejs ghostwriter hunspell telegram-desktop git

Some listed applications may require a separate download or may not be available under that exact package name. Examples to check separately include FreeTube, Android Studio, Tor Browser, and Vivaldi.

Drivers and multimedia

These packages are intended for Intel graphics and firmware. Confirm that they suit your hardware before installing. 

sudo xbps-install -S intel-ucode linux-firmware-intel mesa-dri intel-video-accel vulkan-loader mesa-vulkan-intel lm_sensors ffmpeg gst-libav gst-plugins-bad1 gst-plugins-good1 gst-plugins-ugly1

If you use GRUB and installed Intel microcode, regenerate its configuration: 

sudo grub-mkconfig -o /boot/grub/grub.cfg

Optional: reduce ext4 reserved space

Ext4 reserves space for system use. Only change this if you understand the trade-off, and first identify the correct root partition. The following example sets the reserved percentage to zero; replace the device with your actual root partition. 

lsblk -f
sudo tune2fs -m 0 /dev/ROOT_PARTITION

Optional: power management with TLP

sudo xbps-install -S tlp tlp-rdw tlp-pd smartmontools
sudo ln -s /etc/sv/tlp /var/service/
sudo ln -s /etc/sv/tlp-pd /var/service/

Check TLP status:

sudo tlp-stat

Optional: scheduled filesystem trim

Enable cron, then create a weekly trim job. Confirm that your storage and filesystem support discard before using trim. 

sudo xbps-install -S cronie
sudo ln -s /etc/sv/cronie /var/service/

Create /etc/cron.weekly/fstrim with these contents:

#!/bin/sh
/sbin/fstrim /

Make the script executable:

sudo chmod +x /etc/cron.weekly/fstrim

Optional: Fastfetch

sudo xbps-install -S fastfetch
printf '%s\n' 'fastfetch' >> ~/.bashrc

Optional: zram

Check the current package instructions before enabling zram; package names and setup steps may change. 

sudo xbps-install -S zramen
sudo zramen make

Optional: virtualization with virt-manager

sudo xbps-install -S libvirt virt-manager qemu
sudo ln -s /etc/sv/libvirtd /var/service/
sudo ln -s /etc/sv/virtlockd /var/service/
sudo ln -s /etc/sv/virtlogd /var/service/

Log out and back in after adding your user to any groups required by your virtualization setup. Consult the installed package documentation for the exact group and service requirements.

PipeWire audio

Install PipeWire and its session manager. The PulseAudio compatibility layer is useful for applications that expect PulseAudio. 

sudo xbps-install -S pipewire wireplumber

Enable WirePlumber and the PulseAudio compatibility layer in PipeWire’s configuration: 

sudo mkdir -p /etc/pipewire/pipewire.conf.d
sudo ln -sf /usr/share/examples/wireplumber/10-wireplumber.conf \
  /etc/pipewire/pipewire.conf.d/
sudo ln -sf /usr/share/examples/pipewire/20-pipewire-pulse.conf \
  /etc/pipewire/pipewire.conf.d/
mkdir -p ~/.config/autostart
    sudo ln -sf /usr/share/applications/pipewire.desktop ~/.config/autostart

PipeWire should be started by your user session, not enabled as a root runit service. Log out and back in, then check the session: 

wpctl status
